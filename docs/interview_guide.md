# 需求访谈提纲（D1–D2）

> 目标：访谈 5–10 个正在找实习/校招的同学，验证「面试后凭记忆复盘不系统」是否是真痛点。
> 原则：问过去的行为，不问假设（"你会用吗"这种问题没有价值，人人都会说会）。
> 每场 15–20 分钟，征得同意后录音，访谈记录本身就是简历素材。

## 开场（1 分钟）

"我在做一个面试复盘的小工具，想先了解大家现在是怎么准备和复盘面试的，不会推销任何东西。"

## 核心问题（按顺序，追问写在每题下面）

### Q1. 你最近一次面试结束后，是怎么复盘的？具体做了什么？

（听事实，不打断。追问：）
- 那次复盘花了多长时间？
- 复盘笔记/结果现在还能找到吗？
- **上一场被问了哪些问题，现在还记得几道？**（这题最能暴露痛点）

### Q2. 这个过程里最麻烦/最烦的是哪一步？

（追问：）
- 你尝试过什么办法解决？（飞书妙记、录音转文字、让朋友 mock……为什么没用起来/坚持不下来）
- 如果当时有个工具帮你做了 X，你会觉得有用吗？——**只在他们自己说出 X 时追问**，不要替他们说

### Q3. 你现在在投多少个岗位？各家的进度你怎么管？

（这是投递追踪功能的验证题，追问：）
- 具体怎么记录？（Excel/备忘录/脑子记）
- 有没有出现过记混/漏跟进的情况？举一个具体例子
- 如果"说一句话就能自动记到对应公司岗位"，你会用吗？还缺什么？

### Q4. 你愿意为这个东西付钱吗？付多少？

（追问：）
- 按次付还是包月？
- 不愿意付的话，什么条件下会愿意？（免费/更准/有人用过说好）
- 记录原文，不要引导。

## 结尾（2 分钟）

- 你身边还有谁也需要这个？能介绍我认识吗？（滚雪球找下一位受访者）
- **请求**：方便的话，下次 mock 面试/真实面试时帮我录一段音（测试集素材），我免费给你出一份复盘报告。——这是收集评测素材的最佳时机，一次解决两个任务。

## 记录模板（每场一份，存 evaluation/data/interviews/）

```
编号: I-01    日期: 2026-11-XX    受访者: XX，XX届，目标岗位 XX
Q1 现状与行为:
Q2 痛点（原话摘录）:
Q3 付费意愿（原话摘录）:
是否愿意提供录音: Y/N
我的判断（访谈后立刻写）: 痛点强/中/弱，因为______
```

## 访谈后的汇总动作（D2 晚）

1. 10 场访谈填完上表
2. 写一页「需求验证结论」：痛点是否成立、现有方案为什么不够、付费意愿分布
3. 这页结论直接变成简历第一段和 README 的"Why"部分
